# StockTradeAppPython

1. The overview of the application --
  This application maily is for computing some stock indicators.  The config.json file can give user a overview what stock indicators are supported by this application. The computation / query results are for references. The author of this application is not liable to the accuracy of the computation results from the application and any outcome generated from the usage of the application.  

2. Pre-requests for the use of the application --
   A. Python Enviroment Setup:
      a. Python version -
         Install 3.12.x or above
      b. Python or Conda environment -
         It is better to create a Python environment on the PC where the application is running on.
         One of the ways is to use the cmd:  python -m venv <an given environment name>.
         Then, use the cmd: pip install -r requirement.txt where requirement.txt can be found in the repository.
